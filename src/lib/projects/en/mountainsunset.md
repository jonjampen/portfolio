## Overview

**Mountain Sunset** is a highly personalized dark theme developed for Visual Studio Code. It combines a deep slate palette with vibrant orange highlights and soothing blue accents, creating an aesthetic that reduces eye strain during long coding sessions.

## Design Goals

Creating a comfortable coding interface requires balancing visual interest with readability. The design goals for the theme were:

- **Contrast Management**: Ensuring text syntax highlighting remains highly readable against dark backgrounds.
- **Calming Visuals**: Incorporating warm tones (orange/terracotta) and cool tones (soft blues) inspired by natural mountain landscapes at sunset.
- **Consistency**: Crafting a cohesive experience across all VS Code UI elements, including sidebars, terminal text, editor widgets, and status bars.

## Reception

Published publicly on the VS Code Marketplace, the theme has gained community traction, reaching **over 200 active installations** by developers seeking a cozy, customized workspace.
