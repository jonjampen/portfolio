## Overview

A high-performance fractal sandbox built with React and HTML5 Canvas API. This project allows real-time interactive zooming and panning into the complex plane representing the Mandelbrot Set.

## Features

- **Interactive Zoom & Pan**: Mouse-driven navigation with dynamic boundary recalculations.
- **Custom Color Palettes**: Mathematical palette generators based on iteration escapes.
- **Multithreading Potential**: Experiments using Web Workers to prevent main thread blocking during intensive iteration calculations.
