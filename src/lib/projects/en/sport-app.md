## Overview

A dynamic web application built for local sports clubs to schedule, run, and broadcast live tournament match stats and score leaderboards.

## Features

- **Live Leaderboard**: Real-time points standing table utilizing persistent client connections.
- **Match Scheduling**: Drag-and-drop match calendar coordinator with automated round-robin pairing.
- **Audience Mode**: Optimized mobile-friendly view for spectators to watch live updates.
