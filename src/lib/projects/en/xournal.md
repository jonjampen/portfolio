## Overview

The **Obsidian Xournal++ Integration** plugin provides an automated bridge between Xournal++ (`.xopp`), an open-source note-taking tool for handwriting, and Obsidian. This resolves a common workflow gap for researchers, students, and engineers who want to manage handwritten diagrams and structured text notes in a unified workspace.

## Features

- **Automated PDF Rendering**: Automatically tracks changes to `.xopp` files and exports high-quality vector PDFs.
- **Embedded Document Preview**: Generates inline markdown embeds to preview the rendered handwriting in Obsidian vaults.
- **Strict Linting & CI/CD**: Built with a modern zero-warning ESLint v9 architecture and automated release deployment workflows.
- **Offline First**: All processing and rendering is performed locally inside the Obsidian application sandbox.
