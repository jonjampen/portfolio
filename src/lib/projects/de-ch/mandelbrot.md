## Übersicht

Ein interaktiver Fraktal-Viewer, der mit React und der HTML5 Canvas API entwickelt wurde. Erlaubt stufenloses Zoomen und Verschieben im komplexen Zahlenraum der Mandelbrot-Menge in Echtzeit.

## Features

- **Interaktiver Zoom**: Schnelle Navigation per Maus mit dynamischer Neuberechnung der Grenzwerte.
- **Benutzerdefinierte Farbpaletten**: Mathematische Algorithmen berechnen Farbverläufe basierend auf den Iterationsschritten.
- **Web Workers**: Auslagern der rechenintensiven mathematischen Iterationen in Hintergrundthreads, um UI-Ruckler zu vermeiden.
